# Time-Space-Diagram-for-We
열차운행도표(다이아)를 쉽게 만들 수 있도록 해드립니다 - Idea by @Bigurban | Realized with Google Gemini

## 버전업 데이터
* 버전 1.0.0 (ROK 108(2026). 10. 11)
  - 총 노선 길이, 예상 역 개수, 표정속도, 정차 시간 등 직관적인 변수만 입력하면 요구되는 총 편성 수와 대략적인 배차간격을 도출해 주는 기능, 패턴 시간표 및 다이아그램 시각화 자동화 기능 등 추가

* 버전 1.1.0 (ROK 108(2026). 10. 11)
  - 시간대별 배차간격(RH/NH) 적용 및 4대 운행 패턴(평행, 완급결합, 선택정차, 지역분리) 반영
 
* 버전 2.0.0 (ROK 108(2026). 10. 14)
  - 새벽 시간대 중간역 주박(타절)과 절대적인 영업 종료 시각을 적용
  - 체크박스 조합만으로 평행, 완급결합, 선택정차, 지역분리라는 4대 운행 패턴을 완벽하게 구현하도록 조정
  - 물리 엔진이 통과역(Skip)의 거리를 병합하여 정속 주행을 유지
  - 다국어(한국어, 영어, 일본어) 지원
  - 대대적 UI 리뉴얼
